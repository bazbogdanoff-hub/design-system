## 6 · Known gotchas

- **figmosha wedges on big node walks.** Any snippet traversing instance subtrees
  across many screens times out (>120s), and a killed client leaves the plugin
  running (no cancel) → zombie edits, duplicate creates, sometimes the bridge dies.
  Rule: **≤4 screens per exec** for anything that walks nodes; **≤5** for
  `createTextStyle`. `createVariable` is fine in bulk (280 in one call).
  Recovery: wait, or user restarts the plugin; restart `bridge.mjs` to clear a
  stuck `pending`.
- **Redefining a text style via the API ≈ 50s each** in this file (synchronous
  reflow of every node using it). Don't batch-redefine styles via the API.
- **Version restore unwinds the migration.** If the user restores a Figma version
  before a `safe-edit:` checkpoint, re-run the affected `migration/*.js` (all
  idempotent). This already bit once — `color/border/highlight` vanished and was
  re-applied.
- **Figma UI is stale after plugin writes.** Close/reopen the Variables panel to
  see changes.
- **`strokesIncludedInLayout`** (Figma auto-layout advanced → Strokes → Excluded)
  controls whether a stroke inflates a hug-sized frame. `false` = layout-neutral
  (matches CSS `box-shadow: inset`, NOT CSS `border` on an auto-height element).
  This was the "Card problematic vs Card normal" bug — the only difference between
  those two components.

## 7 · Component work — where to resume

### Card — one open decision

`docs/components/Card.md` is the spec. Final API:
```tsx
<Card padding="none|sm|md|lg" asChild>{children}</Card>
```
padding 0/12/16/20 (`space/*`), default `md`. No elevation, no interactive/hover
(deferred to when alpha tokens land). Fixed glass look: `#fcfcfc` fill, radius 16,
top+left 1.5px white catch, `inset 4px 4px 16px #f0f0f0` vignette.

**OPEN:** `Card.module.css` currently uses `border-top`/`border-left` (reverted
from a `box-shadow: inset` version). On an auto-height element CSS `border` adds
to height — to match Figma `Card normal` (`strokesIncludedInLayout: false`) the
border should be `box-shadow: inset 1.5px 1.5px 0 0 var(--color-card-border)`.
**Ask the user which they want before changing it.** In Figma they've already set
the stroke to Excluded on their component.

Then: user builds `Card` in Figma (4 padding variants, open auto-layout, inner-
shadow effects, bindings per the doc). Then extract the built component and
reconcile.
